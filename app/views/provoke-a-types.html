Provoke-a-types

While in the early stages of the project we utilised provoke-a-types to visuealise the problem space. These we used to create visuals to discuss as a team via lucid boards. Some interactions will not work as these were created as disposable designs to discuss and not test.

Journeys
Name Description
Create a case Exploring the process of manually creating cases journey consists of :
  1. Capturing case meta data
  2. Adding one or more customer
  3. Reviwing data prior to creating case
Find a case Allowing users to enter a name or NINO and be return any matches these can be both closed and open cases.
Pausing work Allowing user to pause/put on hold/BF a case
Transferring tasks Allowing users to transer a task to another agent or function
Handing over a case Allowing users to Handover an entire case to another function or agent.
